How to use this tab
  1. This is the list of words customers really typed into Amazon before buying your best-selling bulbs. It is Amazon's own data, not a guess.
  2. Look for Opportunity — it means many people search this word, but your bulb hardly ever shows up for it. Those are your best chances.
  3. Long-tail means a longer, more exact phrase (3–6 words). Fewer searches, but the customer knows what they want, so they buy more often.
  4. The Top-Moving ASINs table lower down shows the bulbs these words came from. Each month is marked ✓ if it sold more than 5, and the Months above 5 column counts the ticks — a bulb is included when it has 2 or more out of 3.
  5. Use Month to see one month at a time, and ASIN to see the words for one product.
  6. Click Searches / mo at the top of the column to sort biggest first.
  7. Looking a product up in the Listing tool? The blue boxed codes are ASINs (like B08G4YZDH5) — paste those into the tool's ASIN box. Plain codes like LDMG125E278_VDS are SKUs — paste those into the SKU box. Putting a SKU in the ASIN box finds nothing.

How to use this tab — your monthly to-do list
  1. You sell the same bulb twice. One listing sells; the other sells nothing. Often the dead one is simply missing the words customers search for. This tab lists those words.
  2. There are three jobs, and they are different:
    Part A — the listing is empty (no bullet points, no keywords). It needs writing. The column Keywords ready to use tells you how many proven words are already waiting from the good twin.
    Part B — the listing has text, but specific words are missing. Each row tells you the word and exactly where to put it.
    Part C — the SKU code is wrong, so these two are not really the same bulb. Fix the code first; do not add keywords.
  3. In Part B, read the What to do column and follow it exactly:
    Add to backend put it only in the backend keyword box
    Add to bullets put it only in the bullet points
    Add to backend + bullets put it in both
  4. Work in batches. Set What to do to “Add to backend”, do all of those in Seller Central in one go, then switch to the next one. Much faster than going listing by listing.
  5. Start with the biggest numbers. The list is already sorted by monthly searches, so the top rows are worth the most. Words fewer than 10 people searched are left out — they are not worth your time. You can still see every word on the Phase 1 tab.
  6. When you have finished a listing, set View to “By listing” and click its button to mark it done.
  7. Looking a listing up in the Listing tool? The blue boxed codes are ASINs (like B08G4YZDH5) — paste those into the tool's ASIN box. Plain codes like LDMG125E278_VDS are SKUs — paste those into the SKU box. Putting a SKU in the ASIN box finds nothing.
Two things to know. Nothing here touches Amazon — you make the changes yourself, so nothing can go wrong by accident. And if a word does not suit the bulb, do not add it — the report finds words that work, but only you can judge whether a word really describes that product. Amazon does not like keywords that do not match.
This report changes nothing on Amazon. It shows where each proven keyword should go — a person adds it. (The source document's automatic push is deliberately out of scope.)

How each figure is decided. Keywords come from Amazon Search Query Performance, the ASIN-level view the source requires, for 2026-05-01 → 2026-07-31 — the last 3 complete months, assembled from Amazon's weekly rows with rates recomputed from their numerator and denominator, never averaged, and the months kept separate as the source insists · Top-Moving = more than 5 units in at least 2 of 3 months, within the requester's own “Bulbs” category · top 50 keywords per ASIN per month, terms with no purchases dropped · a keyword only reaches the Part B list if at least 10 people searched it in a month (Phase 1 is unfiltered, so the full set is still there) · base SKU = pack size, trailing markers and account suffixes stripped, using the SKU mapping table (mapped_sku); bundles kept whole · underperforming = no sales in 6 months (counted from the product list, so listings absent from the sales report still count) or falling every month · a keyword counts as present if all its words appear anywhere in the text, any order, ignoring capitals and punctuation · a pair is rejected when the two listings state a different wattage or cap fitting.
A click rate shown in amber is above 100% — Amazon's own figure, which happens when one search produces several clicks on a term whose recorded volume is very low. Hover any long title or note to read it in full.
